Upstream declaration reference material
=======================================

The published @cloudbase/adapter-interface@0.7.1 and
@cloudbase/adapter-wx_mp@1.3.1 packages declare ISC but provide no standalone
license/copyright file. localstorage-memory@1.0.3 declares MIT in its package
metadata and README, but likewise supplies no standalone copyright/license file.

Aurora preserves each original package.json and includes the unmodified SPDX
MIT/ISC reference text corresponding to those declarations. Reference text
placeholders are NOT an assertion of these packages' copyright holder/year.
Aurora does not invent an absent copyright notice or claim an upstream notice
file was supplied. This records the actual public upstream distribution, not
additional permission or a legal compatibility determination.

Reference text source: https://github.com/spdx/license-list-data/tree/main/text
Upstream package material: official npm tarballs for the versions named above.
